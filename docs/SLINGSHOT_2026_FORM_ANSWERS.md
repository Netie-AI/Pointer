## ABOUT YOUR SOLUTION

### B-01. Which country is your solution applicable to?
```
Primary go-to-market: Singapore and Malaysia — Windows-heavy knowledge work, multilingual (English/Malay/Chinese) meetings, and strong demand for privacy-aware AI. Expand next to Indonesia, Philippines, and other ASEAN markets with similar laptop workflows. Product is globally applicable wherever Windows desktops dominate, but SEA multilingual STT and PDPA-style governance are designed first for Singapore–Malaysia.
```

### B-02. Total Addressable Market (in USD)
```
Global AI agents / intelligent process automation ~USD 20B+; SEA productivity + creator automation serviceable market multi-hundred million USD, expanding with computer-use adoption.
```

### B-03. Marketing strategy
```
Premium demo-led narrative: “Your laptop becomes real AI—governed.” Lead with visceral demos (frame screen → approve action → video/doc completed; meeting notes in Malaysian rojak). Channels: SWITCH/SLINGSHOT visibility, LinkedIn founder content, SEA creator communities, and MSP/reseller co-marketing. Scarcity pilots with forward-deployed setup for early teams. Proof before scale: case studies on time saved, auditability, and zero ungated high-risk actions. Later: product-led freemium/desktop download with upgrade to team governance and Cortex cloud brain.
```

### B-04. USP and competitive advantage
```
USP: governed computer-use on the real Windows desktop—vision + local multilingual speech + Clicky screen agent + human approval + tamper-evident audit—not a chat box that cannot click, and not an ungated agent that can spend or delete silently.

Competitors: Anthropic Computer Use / OpenAI operators (powerful but cloud-centric and enterprise-gated); Adept-style / multiagent desktop demos; RPA (UiPath) (brittle scripts, weak natural language); consumer copilots (ChatGPT/Claude apps) that advise but do not safely operate native apps; cloud dictation that leaks mic audio.

Compare: Pointer is laptop-native, fail-closed when the gate is down, treats on-screen text as untrusted data, keeps personal brain on device, and is tuned for SEA multilingual work and everyday creator/productivity actions (video edit, copy, paste, fill) under auditable control.
```

### B-05. Pricing strategy
```
Freemium desktop for individuals (core ask/act recipes + limited transcription). Pro subscription for power users (unlimited STT, video/workflow recipes, longer memory). Team / Business: seat-based with shared audit ledger, approval policies, and Cortex-connected fleet learning (no raw secrets to LLM). Pilot pricing: setup + monthly retainer for SME cohorts. Value metric: hours saved on repetitive desktop tasks + compliance/audit readiness vs classic RPA project fees.
```

### B-06. Sales strategy
```
Hybrid: inbound product-led (demo videos, SLINGSHOT/SWITCH, content) plus outbound consultative selling to SMEs and creator teams. Early stage is value-based and FDE-assisted (install, policy templates, first recipes). Later: MSP/partner-led outbound across Singapore–Malaysia Windows fleets. Sales motion emphasizes trust—approval UX, kill switch, and audit—then ROI on repetitive tasks.
```
